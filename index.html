GitHub-Sync (lesen)

Lädt die Rezepte beim Start automatisch von einer Quelle (z.B. rezepte.json im selben Repo oder einer vollständigen URL). Feld leer = kein Sync.

Ist unten der Schreib-Sync mit Token eingerichtet, werden Änderungen (Bearbeiten, Neu, Löschen) automatisch ins Repo zurückgeschrieben und die Quelle wird nicht mehr blind überschrieben.

GitHub-Schreibzugriff (Token)

Damit werden Bearbeiten, Neu und Löschen direkt ins Repo gespeichert – geräteübergreifend. Nötig ist ein fine-grained Token mit Contents-Schreibrecht für genau dieses Repo.

Der Token wird nur lokal auf diesem Gerät gespeichert (localStorage), nie an Dritte übermittelt – ausschliesslich an api.github.com.

Rezept-Scan (KI)

Erlaubt im Rezept-Formular das Einlesen von Foto oder PDF. Die Vorlage wird an die Anthropic-API geschickt und als Rezept vorausgefüllt – du prüfst und speicherst selbst.

Der Key bleibt lokal auf diesem Gerät und geht nur an api.anthropic.com. Er wird nicht ins Repo geschrieben und nicht exportiert.
